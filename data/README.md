# CrashGuard data directory

Large third-party archives are retained under `raw/` with their original
filenames and are not silently mixed with generated data.

- `HealthLINK_Falls_Dataset.zip` was downloaded from the SDSU HealthLINK OSF
  archive at `https://osf.io/download/n27yz/`. It is audited as the source
  archive associated with the supplied human-fall base paper, but is excluded
  from motorcycle performance evaluation because the mounting domain and
  available labels do not match CrashGuard.
- `PMC6660605_SupplementaryFiles.zip` was downloaded from the Europe PMC
  supplementary-file endpoint for the open-access Data in Brief article
  DOI `10.1016/j.dib.2019.103828`. The extracted `mmc2` and `mmc3` folders
  contain seven extreme manoeuvre recordings and four controlled PTW falls.
- `generated/simulated_imu.csv.gz` contains 675 deterministic ten-second
  events at 100 Hz. The generator fixes random seed 20260828, gzip timestamp
  zero, and the embedded filename so repeated runs are byte-identical.

Verify source and generated bytes from the Review-2 directory with:

```sh
sh data/download_datasets.sh
sha256sum -c data/manifest.sha256
```

The exact processing commands, units, labels, exclusions, and limitations are
documented in the Review-2 paper and in `analysis/README.md`.
